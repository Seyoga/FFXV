# Demonization Features

Справочник по системе демонизации мобов и особым демоническим слизням.

## Демонизация мобов

| Параметр | Значение |
|---|---|
| API | `Demonization.apply(...)`, `applyPermanent(...)`, `damageOrDemonizeOnLethalHit(...)` |
| Хранение состояния | скрытый `StatusEffect` `legacyofthelucii:demonization` |
| Длительность по умолчанию | постоянная, `Integer.MAX_VALUE` тиков |
| Синхронизация | status effect + `DemonizationNetwork` |
| Цели | только живые `MobEntity` |

Демонизация не применяется к игрокам, стойкам для брони, удалённым сущностям и уже мёртвым сущностям.

При успешной демонизации моб:

- получает скрытый эффект без частиц, HUD-иконки и изменения атрибутов;
- становится persistent и не должен исчезать обычным despawn;
- запоминает UUID игрока-демонизатора в NBT `LegacyOfTheLuciiDemonizer`;
- получает клиентский демонический визуал;
- начинает использовать demon faction AI.

## Источники демонизации

Подключённые точки Ардина:

- `Ctrl + 2` без предмета в руке: пусторукий рывок;
- `Ctrl + 2` с предметом/оружием: обычный Ardyn Warp Strike;
- финальный удар `Ardyn Barrage` при `12` зарядах.

Если подходящий моб должен умереть от такого удара, он вместо смерти становится демоном с полным HP.

Отладочная способность:

- `Ctrl + 7`;
- ищет моба по прицелу в радиусе `12` блоков;
- принудительно демонизирует цель;
- нужна только для тестирования.

## Поведение демонов

Демонизированные мобы получают:

- `DemonTargetGoal`;
- `DemonMeleeAttackGoal`;
- для слизней дополнительно `DemonHeadgrabGoal`.

Правила фракции:

- демон не атакует самого себя;
- демон не атакует своего демонизатора;
- демон не атакует других демонизированных мобов;
- демон не атакует игроков в креативе или спектаторе;
- демон не атакует стойки для брони;
- friendly fire от демонов блокируется, когда Minecraft сообщает демона как атакующего.

## Визуал демонов

Клиентская часть:

- демонизированные мобы получают затемнённый фиолетово-чёрный визуальный тон;
- обычные мобы не меняются;
- для слизней используется отдельная демоническая текстура;
- для частиц слизня используется отдельный `demonized_slime_ball` particle.

Текущее ограничение:

- броня, held items и дополнительные feature layers не перекрашиваются общей системой демонизации;
- специальные исключения вроде слайма обслуживаются отдельными mixin/renderer путями.

## Демонические слизни

Демонизированный слизень использует захват вместо обычного контактного урона. Ванильный физический урон слизня отключён для всех headgrab-режимов.

Режим определяется размером:

| Размер слизня | Режим | Условие успеха QTE | Воздух | Высасывание HP | Лимит попыток |
|---:|---|---:|---|---|---:|
| `1` | Small | `> 50%` | да, за `100` тиков | нет | нет |
| `2` | Medium | `> 75%` | нет | да | `15` |
| `> 2` | Large | `> 95%` | да, за `140` тиков | да | `15` |

Общее поведение захвата:

- цель фиксируется на сервере в точке начала захвата;
- игрок не может двигаться и прыгать до выхода;
- слизень привязывается к игроку визуально и серверно;
- QTE запускается удержанием `Space`;
- шкала QTE идёт вверх-вниз за `28` тиков;
- после неудачной попытки действует короткий cooldown `10` тиков;
- после успешного выхода слизень отбрасывается и `3` секунды не может начать новый захват;
- если слизень получил урон, он `1` секунду не может начать новый захват;
- сообщения о выходе из захвата выводятся через action bar над хотбаром/XP-баром;
- при выходе проигрывается звук `ENTITY_EXPERIENCE_ORB_PICKUP`.

## Small Slime

Маленький демонический слизень:

- садится на голову игрока;
- визуально растёт до `1.18` масштаба за `12` тиков;
- высасывает воздух за `100` тиков;
- после окончания воздуха наносит drowning damage `2.0` раз в `20` тиков;
- выбирается без лимита попыток, если QTE отпущен выше `50%`.

## Medium Slime

Средний демонический слизень:

- становится вплотную перед игроком;
- фиксирует игрока на месте;
- не высасывает воздух;
- каждые `3` секунды наносит `2.0` урона магией;
- если урон прошёл, увеличивает себе max HP на `2.0` и лечится на `2.0`;
- для выхода нужно отпустить QTE выше `75%`;
- после `15` неудачных попыток срабатывает автоматический побег.

## Large Slime

Большой демонический слизень:

- поглощает игрока целиком;
- фиксирует игрока на месте;
- высасывает воздух за `140` тиков (`7` секунд);
- после окончания воздуха наносит drowning damage `2.0` раз в `20` тиков;
- каждые `3` секунды дополнительно высасывает `2.0` HP и передаёт себе max HP/лечение;
- для выхода нужно отпустить QTE выше `95%`;
- после `15` неудачных попыток срабатывает автоматический побег.

## Помощь другого игрока

Если другой игрок ударяет слизня, который уже держит жертву:

- активный захват сразу прерывается;
- удар по слизню не отменяется и наносит обычный урон;
- жертва получает action bar-сообщение о помощи союзника;
- сам захваченный игрок может бить слизня, но не может своим ударом мгновенно освободиться.

## Деление демонических слизней

Если демонический слизень делится после смерти:

- дочерние слизни получают демонизацию от родителя;
- UUID демонизатора копируется;
- дочерние слизни продолжают использовать demon faction/headgrab механику.

## Сетевые части

Сервер:

- `DemonHeadgrabSystem` хранит активные захваты и cooldown по UUID слизней;
- `DemonHeadgrabNetwork` принимает QTE input и отправляет состояние захвата/QTE;
- `DemonFaction` отвечает за правила урона, friendly fire и rescue-hit.

Клиент:

- `DemonHeadgrabClient` рисует QTE HUD;
- HUD выбирает текстуры шкалы по размеру слизня;
- `DemonHeadgrabVisualState` хранит визуальную привязку слизня;
- `DemonHeadgrabSlimeScaleMixin` применяется только к маленьким слизням на голове.
