# Royal Arms Abilities

Текущий справочник по реализованным способностям Royal Arms. Базовый максимум маны: `100`.

В креативе мана не ограничивает способности: она восстанавливается до максимума и не тратится на проверки стоимости.

## Мана и состояние

| Параметр | Значение |
|---|---:|
| Базовый максимум маны | `100` |
| Задержка регена после траты | `5` секунд |
| Обычный реген | `+1` мана/сек |
| Реген в Overkill | `+1` мана каждые `4` тика |
| Максимум зарядов Ардина | `12` |

Состояние игрока хранит выбранную ветку `Noctis` или `Ardyn`, активность Royal Arms, фильтр предметов, ману, уровень, опыт, заряды Ардина и Overkill.

## Общие действия

| Хоткей | Действие | Условия |
|---:|---|---|
| `R` | Включить/выключить Royal Arms | Нужна разблокированная ветка |
| `H` | Переключить фильтр предметов Royal Arms | Royal Arms может использовать фильтр в способностях |
| `K` | Открыть древо навыков | Нужна разблокированная ветка |
| `Shift + ЛКМ` по предмету | Забрать выбранный предмет из Royal Arms | Игрок должен смотреть на предмет |

Royal Arms нельзя переключать во время анимации включения/выключения. При выключении активные стена, Bind, Shadow Step и Phantom Guard очищаются сервером.

## Пассивная орбита

| Параметр | Значение |
|---|---|
| Доступно | Ноктис, Ардин |
| Условие | Royal Arms активен |
| Мана | `0` |

Урон считается отдельно от каждого предмета, который задевает сущность:

- обычный предмет: `0.2`;
- оружие: `weaponDamage * 1/10`.

Если цель удерживается `Royal Arms Bind`, пассивная орбита не наносит ей дополнительный урон.

Скорость вращения:

- стоя: ускоренное вращение, примерно в `2.5` раза быстрее старого базового режима;
- при приседе: базовая скорость, удобная для выбора предмета;
- при двойном приседе: вращение останавливается до выхода из приседа.

У Ардина при накоплении зарядов орбита визуально делится на внешний и внутренний круг. Внутренний круг вращается быстрее внешнего и в противоположном направлении.

## Временная стена

| Параметр | Значение |
|---|---|
| Доступно | Только Ноктис |
| Хоткей | `Ctrl + 1` |
| Стоимость | `20` маны |
| Размер | `5 x 3` блока |
| Дистанция постановки | до `5` блоков |

Поведение:

- ставится перед игроком по направлению взгляда;
- состоит из временных блоков `royal_arms_wall`;
- временные блоки имеют коллизию и добываются обычным способом;
- дроп и опыт не выдаются;
- существующие блоки мира не заменяются;
- блоки берутся из инвентаря как резерв, но не тратятся навсегда;
- если подходящих блоков не хватает, в стене остаются пропуски;
- семена не попадают в пул блоков для стены;
- сломанный сегмент уходит на cooldown и восстанавливается, если место свободно;
- чем выше hardness исходного блока, тем дольше восстановление.

## Подъём блоком

| Параметр | Значение |
|---|---|
| Доступно | Только Ноктис |
| Хоткей | `Ctrl + 1`, если игрок смотрит вниз |
| Стоимость | `5` маны |

Под игроком создаётся временный блок Royal Arms, после чего игрок поднимается на `1` блок. Блок также использует резерв из инвентаря.

## Warp Strike

| Параметр | Значение |
|---|---|
| Доступно | Ноктис, Ардин |
| Хоткей | `Ctrl + 2` |
| Стоимость | `20` маны |
| Дистанция | до `10` блоков |

Общее поведение:

- игрок бросает предмет из основной руки;
- предмет летит до блока или сущности;
- при попадании игрок телепортируется к предмету;
- предмет возвращается в инвентарь;
- если предмет попал в сущность, полёт останавливается.

Урон:

- обычный предмет: `1.0`;
- оружие: `weaponDamage * 1/2`.

У Ноктиса удар наносится основной цели попадания.

У Ардина обычный Warp Strike использует низкую дугу броска, красно-розовый след и финальный удар по области. Радиус финального взрыва: `2.75` блока, отбрасывание: `0.75`.

Если у Ардина в основной руке пусто, `Ctrl + 2` запускает отдельную пусторукую вариацию:

- короткая зарядка: `6` тиков;
- рывок вперёд до `3` блоков;
- урон по сущностям на линии рывка: `1.5`;
- инвентарь не меняется;
- используется краткий демонический визуал как у Shadow Step.

## Ardyn Barrage

| Параметр | Значение |
|---|---|
| Доступно | Только Ардин |
| Условие | `12` зарядов Ардина |
| Хоткей | `Ctrl + 2` вместо обычного Warp Strike |
| Стоимость маны | Как у Warp Strike, если не креатив |
| Длительность обстрела | `4` секунды (`80` тиков) |
| Возврат предметов | до `100` тиков с хаотичными задержками |

Поведение:

- Royal Arms перестаёт вращаться вокруг игрока и используется как боезапас;
- предметы быстро метаются по направлению взгляда с разбросом;
- если предметы в текущем пуле заканчиваются, они заново призываются за спиной/по бокам игрока и продолжают обстрел;
- попадание в сущность наносит урон и оставляет предмет в районе цели;
- промах оставляет предмет на блоке/земле;
- после обстрела выполняется финальный Ardyn impact;
- после финального удара лежащие предметы расщепляются и возвращаются в Royal Arms;
- все `12` зарядов тратятся.

Урон обстрела считается отдельно от каждого выпущенного предмета:

- обычный предмет: `0.5`;
- оружие: `weaponDamage * 0.15`;
- финальный impact использует урон следующего предмета из очереди, умноженный на `2`.

## Royal Arms Bind

| Параметр | Значение |
|---|---|
| Доступно | Ноктис, Ардин |
| Старт/отмена | `Ctrl + 3` |
| Подтверждение атаки | `ЛКМ`, пока цель удерживается |
| Стоимость активации | `25` маны |
| Удержание | `3` маны/сек |
| Дистанция выбора цели | до `16` блоков |

Поведение:

- `Ctrl + 3` по цели запускает подготовку;
- предметы Royal Arms подлетают и встают вокруг цели;
- цель фиксируется на сервере;
- повторный `Ctrl + 3` отменяет способность;
- при отмене предметы откатываются наружу, исчезают и возвращаются в Royal Arms;
- `ЛКМ` подтверждает удар, после чего предметы вонзаются в цель;
- если цель умирает от урона за попытку движения, предметы также пронзают цель и возвращаются.

Финальный урон считается отдельно от каждого предмета:

- обычный предмет: `0.1`;
- оружие: `weaponDamage * 1/20`.

Урон за попытку движения:

- цель возвращается к точке удержания;
- урон: `max(0.1, totalBindDamage * 0.25)`;
- cooldown урона за движение: `10` тиков.

## Phantom Guard

| Параметр | Значение |
|---|---|
| Доступно | Только Ноктис |
| Хоткей | `Ctrl + 4`, переключение |
| Условие | Royal Arms активен |
| Удержание | `2` маны/сек |
| Перехват снаряда | `5` маны |
| Радиус обнаружения | до `14` блоков |
| Максимальное время подвода предмета | `6` тиков |

Поведение:

- предметы Royal Arms перестраиваются в защитную формацию из трёх рядов;
- способность ищет летящие в игрока снаряды;
- ближайший подходящий предмет идёт на линию перехвата;
- если ближайший предмет по текущей траектории не успевает, орбита ускоряется по своему направлению, чтобы следующий предмет в цепочке успел закрыть игрока;
- перехваченный снаряд останавливается на сервере, падает вниз и больше не летит в игрока;
- если маны не хватает на удержание или перехват, защита отключается;
- используются предметы из текущего пула Royal Arms.

Защита от взрывов:

- входящий взрывной урон снижается при активной защите;
- снижение: `10%` за каждый предмет Royal Arms;
- максимум снижения: `70%`;
- сервер отменяет исходный удар и применяет пересчитанный урон.

## Shadow Step

| Параметр | Значение |
|---|---|
| Доступно | Только Ардин |
| Хоткей | `Z`, удержание |
| Стоимость | до `25` маны за полный рывок |
| Длительность | до `1.5` секунды (`30` тиков) |
| Урон | нет |
| Скорость | `1.15` |

Поведение:

- при старте появляется короткий чёрный силуэт;
- затем игрок скрывается, остаётся тёмный пепельный след;
- есть красноватый экранный фильтр;
- во время движения игрок не отбрасывает тень и не издаёт шаги;
- урон от падения во время Shadow Step и коротко после выхода отменяется сервером;
- если Ардин с активным Royal Arms падает примерно `10+` блоков и до земли остаётся до `5` блоков, Shadow Step автоматически включается как аварийное приземление;
- мана тратится постепенно, пропорционально времени удержания.

## Ardyn Point Warp

| Параметр | Значение |
|---|---|
| Доступно | Только Ардин |
| Выбор метки | удерживать `X` |
| Старт | `ЛКМ`, пока метка выбрана |
| Отмена/остановка | отпустить `X` или нажать `Space` |
| Дальность метки | до `48` блоков |
| Скорость полёта | `17.5` блоков/сек, синхронизирована с Shadow Step |

Поведение:

- при удержании `X` клиент выбирает блок по направлению взгляда и рисует метку над его верхней гранью;
- сервер повторно проверяет блок, дистанцию, видимость и свободное место для посадки;
- после `ЛКМ` игрок летит к метке с пепельным визуалом без красного Shadow Step-фильтра;
- во время полёта игрок не отбрасывает шаги и защищён от падения;
- во время перемещения мана Ардина постепенно восстанавливается по `+1` каждые `4` тика, если игрок не в креативе;
- при достижении цели игрок ставится на верхнюю грань выбранного блока.

## Заряды Ардина

| Параметр | Значение |
|---|---|
| Доступно | Только Ардин |
| Максимум | `12` зарядов |
| Источник | Успешное касание пассивной орбитой |
| Звук | На `3`, `6`, `9`, `12` зарядах |

Поведение:

- каждый успешный урон пассивной орбитой Ардина добавляет `1` заряд;
- при достижении каждой группы по `3` заряда играет звук;
- чем выше группа зарядов, тем выше pitch звука;
- с `3` зарядов Royal Arms визуально делится на два кольца;
- внутреннее кольцо вращается быстрее внешнего и в противоположном направлении;
- при `12` зарядах `Ctrl + 2` заменяется на Ardyn Barrage.

## Неумирающий демон

| Параметр | Значение |
|---|---|
| Доступно | Только Ардин |
| Тип | Пассивная способность |
| Хоткей | нет |
| Условие входа | Первый смертельный урон по Ардину |

Поведение:

- первый смертельный урон переводит Ардина в состояние `Overkill` вместо смерти;
- при входе сбрасывается урон от падения, проигрывается звук Wither Spawn и создаются демонические частицы;
- в Overkill шкала маны работает как таймер восстановления;
- обычные траты маны заблокированы;
- когда мана восстанавливается до максимума, Overkill завершается;
- если здоровье в Overkill снова падает до `0`, игрок умирает обычным образом;
- при смерти/респавне состояние очищается, чтобы эффекты и изменённые сердца не сохранялись.

## Демонизация от атак Ардина

Некоторые добивающие атаки Ардина не убивают подходящего моба сразу, а переводят его в демонизированное состояние с полным HP. Подробности вынесены в [DEMONIZATION_FEATURES.md](DEMONIZATION_FEATURES.md).

Подключённые точки:

- `Ctrl + 2` Ардина без предмета в руке;
- обычный `Ctrl + 2` Ардина с оружием/предметом;
- финальный удар `Ardyn Barrage`.

## weaponDamage

```text
weaponDamage = sum(GENERIC_ATTACK_DAMAGE modifiers in MAINHAND) + 1.0
```

Предмет считается оружием, если:

- имеет модификатор `GENERIC_ATTACK_DAMAGE`;
- или находится в теге `legacyofthelucii:royal_arms_weapons`.

Если итоговое значение меньше или равно `0`, предмет считается обычным.
