# Royal Arms Abilities

Текущие значения баланса. Базовый максимум маны: `100`.

В креативе мана не ограничивает способности.

## Мана

- Максимум по умолчанию: `100`.
- После траты маны реген начинается через `5` секунд.
- Реген: `+1` мана в секунду.
- При повышении уровня максимум маны увеличивается на `10`. Система уровней пока временная.

## Общие действия

| Хоткей | Действие | Мана | Урон |
|---:|---|---:|---|
| `R` | Вкл/выкл Royal Arms | `0` | Нет |
| `H` | Сменить фильтр Royal Arms | `0` | Нет |
| `K` | Открыть древо навыков | `0` | Нет |
| `Shift + ЛКМ` | Взять выбранный предмет из Royal Arms | `0` | Нет |

Фильтр Royal Arms влияет на способности, которые используют предметы из орбиты.

## Пассивная орбита

| Параметр | Значение |
|---|---|
| Доступно | Ноктис, Ардин |
| Условие | Royal Arms активен |
| Хоткей | Нет |
| Мана | `0` |

Урон считается отдельно от каждого предмета:

- Обычный предмет: `0.2`.
- Оружие: `weaponDamage * 1/10`.

Если цель удерживается `Royal Arms Bind`, пассивный урон орбиты по ней не наносится.

Скорость вращения:

- Без приседа: ускоренное вращение, примерно в `2.5` раза быстрее базового режима.
- При приседе: базовая скорость вращения, удобная для выбора предмета.
- При двойном приседе: вращение останавливается до тех пор, пока игрок не встанет.

## Временная стена

| Параметр | Значение |
|---|---|
| Доступно | Только Ноктис |
| Хоткей | `Ctrl + 1` |
| Мана | `20` |
| Размер | `5 x 3` блока |
| Дистанция | До `5` блоков |
| Урон | Нет |

Поведение:

- Стена ставится перед игроком по направлению взгляда.
- Использует временные блоки Royal Arms.
- Блоки имеют коллизию.
- Блоки можно ломать обычным способом.
- Дроп и опыт не выдаются.
- Стена не заменяет существующие блоки мира.
- Блоки берутся из инвентаря как резерв, но не тратятся навсегда.
- Сломанный сегмент уходит на cooldown и восстанавливается, если место свободно.
- Чем выше hardness исходного блока, тем дольше восстановление.

## Подъём блоком

| Параметр | Значение |
|---|---|
| Доступно | Только Ноктис |
| Хоткей | `Ctrl + 1`, если игрок смотрит вниз |
| Мана | `5` |
| Урон | Нет |

Поведение:

- Под игроком появляется временный блок Royal Arms.
- Игрок поднимается на `1` блок вверх.
- Блок использует резерв из инвентаря.

## Warp Strike

| Параметр | Значение |
|---|---|
| Доступно | Ноктис, Ардин |
| Хоткей | `Ctrl + 2` |
| Мана | `20` |
| Дистанция | До `10` блоков |

Поведение:

- Игрок бросает предмет из основной руки.
- У Ноктиса предмет летит прямо к точке попадания.
- У Ардина предмет уходит немного вперёд по низкой дуге к цели, не выше примерно `1` блока над точкой броска; от стартового силуэта тянется тонкий розово-фиолетовый след к оружию.
- На время броска игрок скрывается, остаётся силуэт/след: голубой у Ноктиса, красно-розовый у Ардина.
- При попадании в блок или сущность игрок телепортируется к предмету.
- Предмет возвращается в инвентарь.
- У Ардина после "ловли" оружия игрок появляется у точки удара, коротко заряжает тьмой руку и бьёт вниз.
- Во время зарядки у Ардина проигрывается встроенная keyframe-анимация через playerAnimator: замах/перехват, наклон всего тела и удар рукой вниз.
- Удар Ардина создаёт розово-фиолетовый сферический взрыв радиусом `2.75` блока с отбрасыванием.

Если у Ардина в основной руке пусто, `Ctrl + 2` запускает пусторукую вариацию варпа:

- Перед рывком есть короткая зарядка на `6` тиков.
- Во время зарядки тьма концентрируется у нижней части правой руки.
- Игрок мимолётно входит в демонический/пепельный визуальный режим, как при Shadow Step.
- Затем игрок резко рывком смещается вперёд до `3` блоков по направлению взгляда.
- Рывок не проходит сквозь коллизионные блоки.
- Урон по сущностям на линии рывка: `1.5`.
- Предмет не требуется и инвентарь не меняется.

Урон считается от предмета в основной руке. У Ноктиса урон наносится цели попадания, у Ардина всем подходящим целям в области удара:

- Обычный предмет: `1.0`.
- Оружие: `weaponDamage * 1/2`.

## Фантомная защита

| Параметр | Значение |
|---|---|
| Доступно | Только Ноктис |
| Хоткей | `Ctrl + 4`, переключение |
| Условие | Royal Arms активен |
| Мана на удержание | `2` в секунду |
| Мана за перехват снаряда | `5` |
| Радиус обнаружения снарядов | До `14` блоков |
| Урон | Нет |

Поведение:

- Предметы Royal Arms перестраиваются в защитную орбиту из трёх рядов.
- Способность отслеживает летящие в игрока снаряды и подводит ближайший подходящий предмет Royal Arms на линию перехвата.
- Если ближайший предмет не успевает по текущей траектории, орбита ускоряется по своему направлению вращения, чтобы следующий предмет в цепочке успел закрыть игрока.
- Перехваченный снаряд останавливается на сервере, затем падает вниз и больше не летит в игрока.
- Если маны не хватает на удержание или перехват, защита отключается.
- Предметы берутся из текущего пула Royal Arms; если предметов нет, перехват невозможен.

Защита от взрывов:

- При активной защите входящий урон от взрыва уменьшается.
- Снижение: `10%` за каждый предмет Royal Arms.
- Максимальное снижение: `70%`.
- Взрывной урон пересчитывается сервером: исходный удар отменяется и применяется уменьшенное значение.

## Shadow Step

| Параметр | Значение |
|---|---|
| Доступно | Только Ардин |
| Хоткей | `Z`, удержание |
| Мана | До `25` за полный рывок |
| Длительность | До `1.5` секунды (`30` тиков) |
| Урон | Нет |
| Защита от падения | Во время Shadow Step и коротко после выхода |

Поведение:

- При старте появляется короткий чёрный силуэт.
- Потом игрок скрыт, остаётся тёмный пепельный след.
- Есть красноватый экранный фильтр.
- Во время движения игрок не отбрасывает тень и не издаёт шаги.
- Урон от падения во время Shadow Step отменяется сервером.
- Если Ардин с активным Royal Arms падает примерно `10+` блоков и перед землёй остаётся до `5` блоков, Shadow Step автоматически включается как аварийное приземление при наличии `25` маны.
- Мана тратится постепенно, пропорционально времени удержания.
- Игрок может отпустить `Z` раньше.

## Заряды Ардина

| Параметр | Значение |
|---|---|
| Доступно | Только Ардин |
| Максимум | `12` зарядов |
| Источник | Успешное касание пассивной орбитой |
| Звук | На `3`, `6`, `9`, `12` зарядах |

Поведение:

- Каждый успешный урон пассивной орбитой Ардина добавляет `1` заряд, до `12`.
- При достижении каждой группы по `3` заряда играет звук.
- Чем выше группа зарядов, тем выше pitch звука.
- Начиная с `3` зарядов Royal Arms визуально делится на два кольца.
- Внутреннее кольцо вращается против направления внешнего.
- Внутреннее кольцо вращается быстрее внешнего.
- Предметы переходят во внутреннее кольцо плавно через изменение радиуса, без резкого скачка.

На `12` зарядах `Ctrl + 2` у Ардина заменяет обычный Warp Strike на barrage-атаку:

- Royal Arms перестаёт крутиться вокруг игрока: предметы используются как боезапас.
- Предметы Royal Arms быстро метаются по направлению взгляда в течение `4` секунд, с широким разбросом.
- Если снаряд попадает в сущность, он наносит урон и остаётся в районе цели.
- Если снаряд не попадает в сущность, он остаётся на земле/в точке попадания.
- Когда предметы в оруженосце заканчиваются, они повторно призываются за спиной/по бокам игрока и снова метаются.
- На `5` секунде игрок телепортируется по направлению взгляда и делает финальный Ardyn impact.
- После финального удара лежащие предметы хаотично расщепляются и возвращаются в Royal Arms.
- Активация тратит все `12` зарядов.
- Инвентарь игрока не тратится, используются только визуальные копии предметов из текущего фильтра Royal Arms.

Урон обстрела считается отдельно от каждого выпущенного предмета:

- Обычный предмет: `0.5`.
- Оружие: `weaponDamage * 0.15`.
- Финальный Ardyn impact использует урон следующего предмета из очереди обстрела, умноженный на `2`.

## Royal Arms Bind

| Параметр | Значение |
|---|---|
| Доступно | Ноктис, Ардин |
| Старт/отмена | `Ctrl + 3` |
| Подтвердить удар | `ЛКМ`, пока цель удерживается |
| Мана на активацию | `25` |
| Мана на удержание | `3` в секунду |
| Дистанция выбора цели | До `16` блоков |

Поведение:

- `Ctrl + 3` по цели запускает подготовку.
- Предметы Royal Arms подлетают с расстояния и встают вокруг цели.
- Цель фиксируется на сервере.
- Пока оружие висит, мана тратится постепенно.
- Повторный `Ctrl + 3` отменяет способность.
- При отмене оружие откатывается наружу, исчезает и плавно возвращается в Royal Arms игрока.
- `ЛКМ` подтверждает удар: оружие вонзается в цель.
- Если цель умирает от урона за попытку движения, оружие также пронзает цель и затем возвращается.

Финальный урон считается отдельно от каждого предмета:

- Обычный предмет: `0.1`.
- Оружие: `weaponDamage * 1/20`.
- Общий урон: сумма урона всех предметов Royal Arms, попавших в текущий фильтр.

Урон за попытку движения:

- Если цель пытается сдвинуться, её возвращает к точке удержания.
- Урон: `max(0.1, totalBindDamage * 0.25)`.
- Cooldown урона за движение: `10` тиков.

`totalBindDamage` считается по формуле финального урона выше.

## Неумирающий демон

| Параметр | Значение |
|---|---|
| Доступно | Только Ардин |
| Тип | Пассивная способность |
| Хоткей | Нет |
| Мана | Не тратится напрямую |
| Условие входа | Первый смертельный урон по Ардину |

Поведение:

- Когда Ардин получает смертельный урон, способность один раз переводит его в состояние `Overkill` вместо смерти.
- Вход работает только для Ардина и не срабатывает повторно, если `Overkill` уже активен.
- При входе сбрасывается урон от падения, проигрывается звук Wither Spawn и создаётся демонический эффект частиц.
- Во время `Overkill` шкала маны работает как таймер восстановления, а не как обычный ресурс для способностей.
- Пока `Overkill` активен, обычные траты маны заблокированы.
- Когда мана восстанавливается до максимума, `Overkill` завершается, состояние синхронизируется клиентам, а визуальный эффект пропадает.
- Если в состоянии `Overkill` здоровье снова падает до `0`, игрок умирает обычным образом.
- При смерти/респавне состояние очищается, чтобы эффекты и изменённые сердца не сохранялись после возрождения.

## weaponDamage

```text
weaponDamage = sum(GENERIC_ATTACK_DAMAGE modifiers in MAINHAND) + 1.0
```

Если итоговое значение меньше или равно `0`, предмет считается без weaponDamage.

Предмет считается оружием, если:

- имеет `GENERIC_ATTACK_DAMAGE`;
- или находится в теге `legacyofthelucii:royal_arms_weapons`.
